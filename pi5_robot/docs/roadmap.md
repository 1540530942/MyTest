# 路线图

## 阶段一：能看、能动、能停

- Web 控制台能访问。
- 相机能出图。
- 小车能手动前进、后退、转向、停止。
- 急停和停止按钮可靠。
- 前方障碍物低于阈值时自动停止。
- 操作写入日志。

当前仓库已经完成仿真版骨架，下一步是替换真实硬件驱动。

## 阶段二：能拍照识别、能简单巡查

- 接入真实相机。
- 接入大模型视觉描述。
- 支持固定巡查点。
- 自动拍照并生成 Markdown 报告。

## 阶段三：能定位、能找目标

- 接入编码器和 IMU。
- 实现里程计。
- 使用 AprilTag / ArUco 校正位置。
- 实现 `localize` 和 `search_target` 工具。

## 阶段四：能追踪

- 接入本地目标检测。
- 使用本地 PID 闭环控制跟随。
- 目标丢失后停车并搜索。
- 保持安全距离和低速。

## 阶段五：ROS 2 / Nav2 升级

- 发布 odom、camera、scan topic。
- 接入 LiDAR 或深度相机。
- 使用 SLAM 建图。
- 使用 Nav2 到点巡查。
