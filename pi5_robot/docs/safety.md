# 安全约束

## 核心原则

1. 大模型不直接控制 GPIO。
2. 每次移动前必须读取状态和障碍物距离。
3. 实时避障、急停、追踪闭环放在本地控制器。
4. 运动命令必须有限速、限距、超时。
5. 自动任务期间允许人工随时接管。
6. 所有动作和异常写入 episode 日志。

## MVP 默认阈值

| 项 | 默认值 |
| --- | --- |
| 最大直线速度 | `0.3 m/s` |
| 最大单次前进距离 | `50 cm` |
| 最大单次后退距离 | `30 cm` |
| 最大单次旋转角度 | `90 deg` |
| 前方停车距离 | `35 cm` |
| 命令超时 | `500 ms` |
| 自动任务最低电量 | `30%` |

配置见 [configs/safety.yaml](../configs/safety.yaml) 和 [configs/tools.yaml](../configs/tools.yaml)。

## 大模型系统提示词要点

```text
你是机器人任务规划 Agent。
你不能直接控制 GPIO。
你只能调用系统提供的受限工具。
每次移动前必须查询机器人状态。
如果前方障碍物距离小于安全阈值，必须停止。
如果定位置信度低，不允许执行长距离移动。
如果工具返回失败，必须重新规划或请求人工接管。
禁止高速移动。
禁止连续执行多个运动命令而不检查状态。
```
