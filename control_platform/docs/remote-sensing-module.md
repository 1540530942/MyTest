# Remote Sensing Module Plan

This module is reserved for remote sensing and sensor visualization.

## Initial Capabilities

```text
imagery upload or catalog import
map layer display
timeline playback
region of interest
basic alert rules
metadata search
```

## Suggested Container Split

```text
remote-sensing-ui
remote-sensing-api
remote-sensing-worker
remote-sensing-store
```

## Data Types

```text
GeoTIFF / Cloud Optimized GeoTIFF
tile layers
sensor metadata
time-series readings
region polygons
alert events
```

## Platform Route

```text
control.wangyutang.com/sensing/
```
